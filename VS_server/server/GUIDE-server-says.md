# 서버가 무엇을 보고 무엇을 말하는가 — 기여자용 한 장

> **범위**: 서버가 **기여자의 선언을 어떻게 검사하고 어떻게 말하는가**.
> ❌ 아두이노 스케치 쓰는 법은 **여기 없다** — arduino 도메인이다.
> **두 문서를 한 장에 섞으면 도메인이 섞이고, 한쪽이 낡을 때 아무도 모른다.**

작성: socket-engineer · 2026-08-19 · 대상 서버 판: `feb3a85` 이후

---

## 0. 🔴 먼저 — **여기 있는 것 중 서버를 못 뜨게 하는 것은 하나도 없다**

```
🗣 아래 검사 다섯은 전부 **말만 한다.** 서버는 뜨고, 등록은 성공하고, 하행도 정상이다
🔴 막는 것은 딱 하나뿐이다 — `--port-offset` 범위 (§5)
```
**왜 안 막나**: 기여자가 *"내 것 때문에 서버가 안 뜬다"* 로 겁을 먹으면 아무도 안 건드린다.
🔑 **판별자는 "증상이 보이는가"다** — 보이면 말하고, **안 보이면 막는다.**
`--port-offset` 만 막는 이유는 **틀린 값이 조용히 엉뚱한 포트를 잡아 증상이 아예 없기 때문**이다.

## 1. 자리를 하나 더하려면 — `조별과제샘플/server/lot.cpp` 한 곳

```cpp
ParkingLot lot;
lot.spot("A1").parking().module("A1").module("B1");   // 주차 자리 · 모듈 둘(이중화)
lot.spot("A2").parking().module("A2").module("B2");
…
lot.spot("E1").label("입구").module("DR");            // 일반영역 — parking() 을 안 적었다

ParkingServer srv(lot);
```
```
· `spot(id)` 는 **같은 id 로 두 번 불러도 안전하다** — 있으면 그것을 돌려준다
· `module(name)` 은 **그 모듈이 어느 자리에 속하는지**를 선언한다. 센서인지 명령인지는 **안 가른다**
· `parking()` 을 **적어야** 주차 자리다 — 안 적으면 일반영역이고 **센서가 없어도 정상**이다
· 🔴 `sensor()`·`actuator()`·`gate()`·`Gate` 는 **없앴다**(v2 · 2026-08-20). 지금 그 이름은 컴파일이 막는다
```
🔑 **위에서 아래로 읽으면 배치가 그대로 보인다.** 자동 배선을 일부러 안 썼다 —
한 줄로 줄일 수 있지만 그러면 **언제 무엇이 붙는지 안 보인다.**

⚠ **이름이 자리 id 와 같을 필요는 없다.** `module("Q7")` 도 된다 — 조립 표가 사상을 준다.
🔴 **다만 그 이름을 장치도 그대로 보내야 한다**(§2 ③).

### 1.1 🔴 **여러 사람이 각자 장치를 붙일 때는 `devid` 를 못 박아라** (2026-08-19 신설)

```cpp
lot.spot("A3").parking().module("P2", "S1");   // 🔴 **P2 장치의** `S1` 만 붙는다
lot.spot("E1").module("P2", "DR");             // 명령 모듈. **점유 판정에 안 쓰인다**
```
```
module(name)          "아무 장치나 그 이름을 가진 것"   ← 장치가 하나뿐일 때 편하다
module(devid, name)   **그 장치의 그 모듈**              ← 여럿이 붙을 때 이것을 써라
🔑 센서·명령을 **안 가른다** — 장치가 등록에서 `kind` 첫 글자로 말한다(`I` 관측 · `O` 명령).
   점유 판정에는 `I` 만 들어가므로 차단봉 상태가 자리 점유로 샐 자리가 **구조적으로 없다**
```
> ### **`devid` 를 주는 순간 "모듈 이름이 자리 id 와 같아야 한다"는 암묵 규칙이 사라진다.**

⚠ **1인자만 쓰면 같은 이름을 두 사람이 쓸 때 앞사람이 이긴다**(§2 ①). 기동 로그가 그것을 말하고,
그때 문구가 **"`module("devid","이름")` 으로 갈라라"** 라고 알려 준다.

🔴 **`devid` 를 안 정했다면 기본값을 의심해라** — 장치 쪽 `DEVICE_ID` 가 안 바뀌면
**모두가 같은 id** 로 붙는다. 로컬에서 혼자 시험할 때는 안 보이고 **합칠 때 전부 충돌한다.**

## 2. 서버가 하는 검사 ~~다섯~~ **여섯** — 문구와 **그때 볼 곳**

### ① 조립 표: 같은 모듈 이름이 두 자리에 — **기동 때**
```
🔴 조립 표 — 모듈 이름 `S1` 이 자리 A1 와 A2 에 둘 다 적혀 있다.
   **앞엣 자리(A1)가 이기고 A2 는 이 모듈을 영영 못 받는다.** `lot.cpp` 의 조립 표에서 한쪽을 고쳐라
```
**왜 이렇게 되나**: 이름→자리 조회가 **처음 맞는 것**을 돌려준다. 둘째는 도달할 수 없다.
**볼 곳**: 서버 기동 로그. **막지 않는다.**

### ② 센서가 하나도 없는 주차 자리 — 🔴 **장치가 등록할 때**(v2 에서 옮겼다)
```
🔴 자리 A3 에 **센서가 하나도 없다**(노드 P1 기준). 화면에는 자리가 보이지만 점유는
   **영원히 `unknown`** 이다 — 고장이 아니라 선언이 빈 것이다
```
🔑 **v2 에서 기동 → 등록으로 옮겼다.** `module()` 하나로 합치면서 **선언만 보고는 센서인지 알 수 없다** —
장치가 `kind` 첫 글자로 말해 주는 **등록이 알 수 있는 가장 이른 시점**이다.
```
   고치는 법: 그 자리에 관측 모듈을 붙인다 — `lot.spot("A3").parking().module("A1")`
```
⚠ **이게 가장 헷갈리는 증상이다** — 자리는 보이는데 값이 안 채워지니 *"센서가 고장났나"* 를 쫓게 된다.
**볼 곳**: 기동 로그 + 화면의 그 자리가 계속 `unknown`. **막지 않는다.**

### ③ 등록: 어느 자리에도 안 붙는 모듈 — **장치가 등록할 때마다**
```
🔴 모듈 `B7` (idx 2, 노드 P9) 은 **어떤 자리에도 안 붙는다** — 지형에 그 이름이 없다.
   **등록은 성공했고 하행도 정상이지만 이 모듈은 화면에 안 나타난다.**
   지금 지형의 자리: A1, A2, A3, A4, A5, E1, X1
   · 자리에 붙이려면 그 자리 id 와 같은 이름을 쓰거나(현행 규칙) 대장에 할당을 걸어라(4단계)
```
> ### 🔴 **이것이 가장 조용한 고장이었다. 오늘 전까지 아무 말도 안 했다.**
> **장치는 `등록 완료` 를 받고, 서버는 정상이고, 그 모듈만 없다.**

**고치는 법 둘 중 하나**:
```
(가) 장치가 보내는 이름을 조립 표의 센서 이름과 맞춘다
(나) 조립 표에 그 이름을 더한다 — `lot.spot("A3").parking().module("B7")`
```
**볼 곳**: 서버 로그 · 요약 줄 **`미결속모듈 N/M`**(M = 결속을 시도한 모듈 총수). **막지 않는다.**

#### 🔴 ⚠ **그런데 이 숫자는 "실수"일 수도 있고 "안 쓰기로 한 것"일 수도 있다** (2026-08-19)

```
`lot.cpp` 가 자리 하나만 선언하고 장치에 모듈이 더 많으면 → **미결속 N** 이 뜬다. **정상이다**
```
🔑 **서버는 둘을 구분할 수 없다** — 선언 안 한 것이 "빠뜨린 것"인지 "끄기로 한 것"인지는
**사람의 뜻**이고 코드에 안 적혀 있다. 그래서 서버는 **사실만 말한다**: *"이 모듈은 어디에도 안 붙었다."*

**읽는 법**:
```
· 내가 **켠 자리에 붙어야 할** 모듈이 여기 뜨면  → 🔴 **실수다.** 이름·devid 를 맞춰라
· 내가 **안 켠 자리의** 모듈이 뜨면              → ✅ **정상이다.** 그게 "비활성"의 모양이다
```
⚠ **그러니 이 수를 보고 놀라지 마라. *어느 모듈인지* 를 봐라** — 문구에 이름과 `idx` 가 있다.

🔑 **그래서 분모를 붙였다** — `미결속모듈 10/12` 는 *"12개 중 10개를 안 쓴다"* 로 읽힌다.
```
⚠ 그래도 **"정상"이라고 라벨하지 않았다**(monitor 지적) —
  **라벨을 붙이면 그 값이 검산 대상에서 빠진다.** 오늘 `센서갈림 3` 이 정확히 그랬다.
🔑 비율만 보여 주고 **판단은 사람이 한다.**
```

### ④ 등록: 한 장치 안에서 이름이 중복 — **장치가 등록할 때마다**
```
🔴 장치 안 모듈 이름 중복 — 노드 P1 의 idx 0 와 1 가 둘 다 'A1' 이다.
   **`(devid,name)` 조회가 애매해진다.** 전선 주소는 `idx` 라 동작은 하지만
   **화면이 둘 중 하나를 임의로 집는다**
```
⚠ **증상이 "가끔 엉뚱한 모듈이 보인다"라서 결함으로 안 보인다.**
**볼 곳**: 서버 로그 · 요약 줄 `이름중복 N`. **막지 않는다.**

### ⑥ 🔴 `devid` 가 예시값 — **장치가 붙을 때** (2026-08-19 신설)
```
🔴 devid 가 **예시값 `P1`** 이다 — 기여자가 자기 것으로 안 바꿨을 수 있다.
   **혼자 시험할 때는 정상 동작하지만, 합치면 같은 이름끼리 서로 쫓아낸다.**
   `client.ino` 의 `#define DEVICE_ID` 를 자기 것으로 바꿔라(1~8자)
```
> ### **이 경고가 왜 여기 있나 — 결함이 *생기는 단계* 와 *드러나는 단계* 가 멀기 때문이다.**
```
② 각자 로컬에서 시험  → 혼자라 **아무 증상이 없다**
③ 합쳐서 한 서버로    → **전부 충돌한다.** 그런데 이때는 원인이 멀리 있다
```
🔑 **②에도 서버가 있다.** 그래서 로컬 서버가 그 자리에서 말한다 — **장치를 안 굽고, 합류를 안 기다린다.**

**볼 곳**: 서버 로그 · 요약 줄 `예시devid N`. **막지 않는다.**
⚠ **혼자 시험하는 동안은 이 값으로도 정상 동작한다** — 그래서 막지 않는다. 다만 **합치기 전에 바꿔라.**

### ⑤ 등록: 두 장치가 같은 이름을 주장 — **장치가 등록할 때마다**
```
🔴 모듈 이름 충돌 — 자리 A1 의 이름 'A1' 을 노드 P2 가 다시 주장한다.
   **먼저 잡은 노드를 유지하고 이것은 결속하지 않는다.**
```
🔑 **먼저 잡은 쪽이 이긴다** — 조용히 덮으면 뒤엣것이 앞엣것을 지워 **원인을 못 찾는다.**
**볼 곳**: 서버 로그 · 요약 줄 `이름충돌 N`. **막지 않는다.**

## 3. 정상일 때도 한 줄 찍는다 — **그게 검사가 있다는 증거다**

```
= 조립 표 검사 — 자리 7개 · 문제 없음
```
🔴 **안 찍으면 검사가 있다는 것을 아무도 모른다.** 그리고 문제가 없을 때와
**검사가 아예 안 돈 때가 똑같이 보인다.**
🔑 요약 줄도 같은 규율이다 — `미결속모듈 0` 처럼 **`0` 을 찍는다.**
**칸이 아예 없으면 `0` 이 아니라 *아무것도* 안 나오고, 받는 쪽은 "안 일어났나 보다"로 읽는다.**

## 4. 요약 줄에서 이 다섯을 한 번에 본다

소크 요약(60초마다 · 종료 시 한 번)에 이 칸들이 있다:
```
… · 이름중복 0 · 미결속모듈 0 · 조립표문제 0 · 이름충돌 0 · … · 대장 2노드(신규 0/재확인 0) 할당 0 저장 2
```
_(위는 실제 출력에서 그대로 뜬 것이다. **순서를 포함해 실물과 맞춰 뒀다** — 순서가 다르면 눈으로 찾을 때 헤맨다.)_
```
이름중복  ④   **미결속모듈 N/M**  ③   조립표문제  ①+②   이름충돌  ⑤   예시devid  ⑥
대장        재기동을 건너 기억하는 노드 수. `재확인` 은 **구성이 대장과 달라 사람이 봐야 하는** 것
```
🔴 **하나라도 0 이 아니면 그 줄에 🔴 가 붙는다.** 붙어 있으면 위 문구를 로그에서 찾아라.

## 5. 🔴 유일하게 **막는** 것 — 손잡이 범위

`--port-offset` 이 범위 밖이면 **서버가 안 뜬다.**
```
--port-offset 은 1 ~ 55544 사이여야 한다 (받은 값: -3)
```
**왜 여기만 막나**: 음수면 0번 포트로, 큰 값이면 `htons` 에서 잘려 **아무 포트에나 붙는다.**
그리고 **아무 증상이 없다** — 나중에 *"서버가 이상하다"* 로 보고된다.
> ### **증상이 보이면 말하고, 증상이 안 보이면 막는다.** 그 판별자로 갈랐다.

`--max-line` · `--down-cap` 도 같은 이유로 범위를 검사하고, 값이 범위 안이면 **시험 전용이라고 크게 찍는다.**

## 6. ⚠ 이 문서가 답하지 **않는** 것

```
· 아두이노 쪽에 모듈을 더하는 법 → arduino 도메인 (루트가 색인을 만든다)
· 관리자 화면에서 할당하는 법   → 아직 없다(온보딩 4단계). `assignments` 는 기록만 된다
· 정책(자리 판정·차단봉 동작) 고르기 → 아직 없다(5단계)
· 🔴 **장치는 "내 이름이 지형에 있나"를 검사할 수 없다** — 지형은 서버만 안다.
  그래서 ③ 은 **서버에만 있을 수 있는 검사**다
```

## 7. 이 문서를 고쳐야 할 때

**검사를 더하거나 문구를 바꾸면 여기도 고쳐라.** 문구는 기여자가 검색할 유일한 단서다.
⚠ **문구와 이 문서가 갈리면 기여자는 검색에 실패하고 "아무 말도 없다"로 읽는다** —
그건 검사가 없는 것과 같다.
